# Калькулятор выплат по вкладу

Веб-приложение на Vue 3 + TypeScript + Vite. Процесс: спецификация (OpenSpec) → тесты → код.
Спецификации и план: `openspec/changes/add-deposit-calculator/` (сначала читать `tasks.md` и `design.md`).

## Команды

- `npm install` — установка зависимостей
- `npm run dev` — запуск в режиме разработки
- `npm test` — модульные тесты (Vitest)
- `npm run test:e2e` — сквозные тесты (Playwright, появятся в группе 7)
- `npm run typecheck` — проверка типов
- `npm run check:bem` — проверка имён классов по БЭМ
- `npm run build` — сборка (проверка типов + Vite)
- `openspec validate --strict add-deposit-calculator` — проверка спецификации

## Правила

1. **Деньги только через `decimal.js`.** Тип `number` для денежных расчётов запрещён.
   Округление до копейки «половина вверх» в каждом периоде.
2. **Тесты до кода.** Сначала коммит с падающими тестами, затем реализация. Название теста
   содержит название сценария спецификации.
3. **БЭМ.** Один компонент — один блок, `блок__элемент--модификатор`, один уровень элементов,
   без вложенных селекторов. Проверяется `npm run check:bem`.
4. **Токены.** Цвета, отступы, радиусы, тени, шрифты — только переменные из `src/styles/tokens.css`.
5. **Русский язык.** Весь текст интерфейса, документы и сообщения коммитов — на русском.
   Английский только для технических имён (ключевые слова OpenSpec, пакеты, идентификаторы).
6. **Документация библиотек** сверяется через context7, а при его отсутствии — по официальным
   сайтам, не по памяти. Версии в `package.json` закреплены точно.
7. **Ядро без интерфейса.** `src/core/` не импортирует Vue и не обращается к странице.
8. **Одна группа задач — одна ветка и один запрос на слияние.** Коммиты мелкие.
