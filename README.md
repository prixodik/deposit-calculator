# deposit-calculator

Калькулятор выплат по банковскому депозиту: простые и сложные проценты, капитализация,
периодичность выплат, график выплат в виде таблицы и итоговая сумма.

Учебный пет-проект, демонстрирующий spec-driven AI-разработку:
спецификация в [OpenSpec](https://github.com/Fission-AI/OpenSpec) → план → тесты → код.

## Процесс

1. Требования оформляются как change-proposal в `openspec/changes/`.
2. Спецификация проверяется командой `openspec validate`.
3. После утверждения спецификации пишутся тесты, затем реализация.
4. Завершённое изменение архивируется (`openspec archive`), требования попадают в `openspec/specs/`.

Статус: идёт работа над спецификацией.
