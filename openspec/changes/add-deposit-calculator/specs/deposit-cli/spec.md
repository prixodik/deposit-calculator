# Spec Delta

## Purpose

Определяет консольную команду `deposit-calc`: как пользователь задаёт параметры вклада и в каком виде
получает график выплат, итоги, CSV-файл и PNG-график роста остатка.

## ADDED Requirements

### Requirement: Параметры командной строки
Команда `deposit-calc` SHALL принимать параметры: `--amount` (сумма), `--rate` (ставка, % годовых),
`--months` (срок), `--start` (дата открытия YYYY-MM-DD, по умолчанию текущая дата),
`--frequency` (`monthly` по умолчанию, `quarterly`, `yearly`, `end_of_term`), `--capitalize` (флаг),
`--csv PATH`, `--chart PATH`. Параметры `--amount`, `--rate`, `--months` обязательны.

#### Scenario: Минимальный набор параметров
- **WHEN** выполнена команда `deposit-calc --amount 100000 --rate 12 --months 12`
- **THEN** команда завершается с кодом 0 и выводит график с ежемесячными периодами без капитализации

#### Scenario: Отсутствует обязательный параметр
- **WHEN** выполнена команда `deposit-calc --amount 100000 --rate 12`
- **THEN** команда завершается с кодом 2 и сообщает в stderr об отсутствии `--months`

### Requirement: Табличный вывод графика и итогов
Команда SHALL выводить в stdout таблицу графика (одна строка на период, колонки как в графике выплат)
и блок итогов: начислено, выплачено, остаток на конец срока, доход. Суммы MUST выводиться с двумя
знаками после запятой.

#### Scenario: Итоги в выводе
- **WHEN** выполнена команда `deposit-calc --amount 100000 --rate 12 --months 12 --capitalize --start 2026-01-15`
- **THEN** stdout содержит 12 строк графика и итоги с остатком на конец срока 112682.51 и доходом 12682.51

### Requirement: Экспорт графика в CSV
При указании `--csv PATH` команда SHALL записать график в файл CSV в кодировке UTF-8: первая строка
содержит заголовки колонок, далее по строке на период; даты в формате YYYY-MM-DD, суммы с точкой
как десятичным разделителем и двумя знаками после неё.

#### Scenario: Создание CSV
- **WHEN** выполнена команда `deposit-calc --amount 100000 --rate 12 --months 12 --csv out.csv`
- **THEN** файл out.csv содержит строку заголовков и 12 строк данных, сумма колонки начисленных процентов равна 12000.00

### Requirement: PNG-график роста остатка
При указании `--chart PATH` команда SHALL сохранить PNG-изображение с графиком: по оси X даты окончания
периодов, по оси Y остаток на конец периода и накопленная сумма выплат.

#### Scenario: Создание PNG
- **WHEN** выполнена команда `deposit-calc --amount 100000 --rate 12 --months 12 --capitalize --chart growth.png`
- **THEN** создан непустой файл growth.png с корректной PNG-сигнатурой

### Requirement: Ошибки ввода
При некорректных значениях параметров команда MUST завершаться с кодом 2, выводить в stderr сообщение,
называющее параметр и причину, и не создавать файлы CSV и PNG.

#### Scenario: Отрицательная ставка в командной строке
- **WHEN** выполнена команда `deposit-calc --amount 100000 --rate -5 --months 12 --csv out.csv`
- **THEN** команда завершается с кодом 2, stderr упоминает `--rate`, файл out.csv не создан

#### Scenario: Некорректная дата
- **WHEN** выполнена команда `deposit-calc --amount 100000 --rate 12 --months 12 --start 2026-02-30`
- **THEN** команда завершается с кодом 2, stderr упоминает `--start`
