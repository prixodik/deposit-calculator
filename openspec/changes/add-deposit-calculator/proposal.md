# Proposal

## Why

Нужен небольшой, проверяемый калькулятор выплат по банковскому депозиту: по сумме, ставке и сроку
он показывает, сколько процентов начислится, когда они будут выплачены или капитализированы и какую
сумму вкладчик получит в итоге. Проект одновременно служит демонстрацией spec-driven AI-разработки,
поэтому формулы, допущения и правила округления фиксируются в спецификации до написания кода.

## What Changes

- Расчёт процентов по депозиту по номинальной годовой ставке:
  - простые проценты (проценты выплачиваются, тело вклада не растёт);
  - сложные проценты (капитализация: проценты прибавляются к телу вклада).
- Периодичность начисления: ежемесячно, ежеквартально, ежегодно, в конце срока.
- Срок вклада задаётся в целых месяцах; неполный последний период рассчитывается пропорционально.
- Денежные суммы считаются точно (десятичная арифметика), проценты за период округляются до копеек
  по правилу «половина вверх».
- График выплат: строка на каждый период с датой, остатком, начисленными, капитализированными и
  выплаченными процентами.
- Итоги: сумма начисленных процентов, сумма выплат, остаток на конец срока, общий доход.
- Интерфейс командной строки: вывод графика таблицей, экспорт в CSV, построение графика роста
  остатка в PNG.
- Валидация входных данных с понятными сообщениями об ошибках.

Вне объёма этого изменения: пополнения и частичные снятия, досрочное расторжение, налог (НДФЛ),
плавающие ставки, расчёт по фактическому числу дней (actual/365), эффективная годовая ставка,
веб-интерфейс.

## Capabilities

### New Capabilities

- `deposit-calculation`: входные параметры вклада, их валидация, правила начисления процентов,
  капитализации и округления, итоговые суммы.
- `payout-schedule`: состав и порядок строк графика выплат, правила дат периодов, согласованность
  графика с итогами.
- `deposit-cli`: командная строка: параметры, табличный вывод, экспорт CSV, PNG-график роста
  остатка, коды выхода и сообщения об ошибках.

### Modified Capabilities

Нет: в проекте ещё нет спецификаций.

## Impact

- Новый Python-пакет и консольная команда в пустом репозитории.
- Зависимости: pytest (тесты), matplotlib (только для PNG-графика). Денежные расчёты используют
  стандартный модуль `decimal`.
