# Design

## Context

Репозиторий пустой (только OpenSpec и README). Мотивация описана в proposal.md, поведение в
`specs/`. Здесь фиксируются технические решения, которые не видны снаружи.

## Goals / Non-Goals

**Goals:**
- Ядро расчёта — чистые функции без ввода-вывода, полностью покрытые тестами по сценариям спецификаций.
- Тонкий CLI-слой поверх ядра; вывод CSV и PNG отделён от расчёта.
- Воспроизводимость: одинаковые входные данные всегда дают одинаковый график до копейки.

**Non-Goals:**
- Публикация пакета в PyPI.
- Локализация вывода и форматирование сумм с разделителями разрядов.

## Decisions

1. **Python 3.12+, пакет в `src/`-раскладке, `pyproject.toml`, консольная точка входа `deposit-calc`.**
   Альтернатива — плоская раскладка; `src/` исключает случайный импорт непроинсталлированного кода в тестах.

2. **Деньги — `decimal.Decimal`, округление `ROUND_HALF_UP` до `0.01` в каждом периоде.**
   `float` даёт ошибки представления (0.1 + 0.2 ≠ 0.3). Округление в каждом периоде, а не только в
   итоге, делает график самосогласованным: сумма строк равна итогу (см. payout-schedule).
   Цена решения — расхождение с замкнутой формулой на копейки; оно зафиксировано сценарием.

3. **Месяц = 1/12 года (конвенция 30/360 на уровне месяцев), а не фактическое число дней.**
   Альтернатива actual/365 ближе к практике российских банков, но усложняет проверку формул и
   зависит от високосных лет. Вынесено за рамки этого изменения; при необходимости — отдельный change.

4. **Модель данных — неизменяемые `dataclass(frozen=True)`: параметры вклада, строка графика, результат.**
   Альтернатива — словари; dataclass даёт типизацию и явный контракт для тестов.

5. **Даты периодов считаются от даты открытия (`start + N месяцев`), а не от конца предыдущего периода.**
   Иначе 31-е число «сползает» к 28-му после февраля. Сложение месяцев реализуется своей небольшой
   функцией на стандартной библиотеке (`calendar.monthrange`), без зависимости `python-dateutil`.

6. **CLI на `argparse`** (стандартная библиотека, код выхода 2 при ошибках разбора по умолчанию).
   Ошибки валидации ядра перехватываются и превращаются в код 2 с сообщением, называющим параметр.

7. **CSV — модуль `csv` стандартной библиотеки; PNG — `matplotlib` с бэкендом `Agg`.**
   matplotlib импортируется лениво, только при `--chart`, чтобы расчёт и тесты ядра не зависели от него.

8. **Тесты — pytest, по одному или нескольким тестам на каждый сценарий спецификации**, с названием,
   отсылающим к сценарию. Тесты пишутся до реализации (TDD). Актуальные API pytest, matplotlib и
   argparse сверяются через context7.

## Risks / Trade-offs

- [Конвенция 1/12 года отличается от банковской actual/365] → явно указано в README и спецификации;
  результаты могут отличаться от калькуляторов банков на несколько рублей.
- [Округление в каждом периоде отличается от замкнутой формулы] → поведение зафиксировано сценарием,
  тест проверяет именно расчёт по периодам.
- [matplotlib — тяжёлая зависимость] → вынесена в optional extra `chart`; без неё `--chart` даёт
  понятную ошибку.
