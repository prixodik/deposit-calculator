# Задачи

## 1. Каркас проекта

- [ ] 1.1 Создать приложение Vue 3 + TypeScript + Vite, настроить строгий режим TypeScript и скрипты `dev`, `build`, `test`, `проверка типов`; проверить: `npm run build` и `npm test` (0 тестов) проходят
- [ ] 1.2 Сверить через context7 актуальную документацию Vue, Vite, Vitest, Vue Test Utils, decimal.js, Chart.js/vue-chartjs и Playwright; записать выбранные версии в `package.json`; проверить: установленные версии совпадают с записанными
- [ ] 1.3 Написать `CLAUDE.md`: стек, команды, правила (деньги только через `decimal.js`, тесты до кода, процесс OpenSpec, текст интерфейса на русском); проверить: команды из файла выполняются как написано

## 2. Ядро расчёта (deposit-calculation)

- [ ] 2.1 Написать тесты проверки параметров по сценариям требования «Проверка входных параметров»; проверить: тесты падают
- [ ] 2.2 Реализовать модель параметров и проверку с русскими сообщениями; проверить: тесты 2.1 проходят
- [ ] 2.3 Написать тесты разбиения на периоды и формулы процентов (5,83; 0,13; 11 875,00); проверить: тесты падают
- [ ] 2.4 Реализовать разбиение и проценты за период на `decimal.js`; проверить: тесты 2.3 проходят
- [ ] 2.5 Написать тесты простых и сложных процентов и итогов (12 000,00; 12 682,51; 110 381,29; 125 440,00; 7 000,00; ставка 0); проверить: тесты падают
- [ ] 2.6 Реализовать расчёт с капитализацией и без, итоги; проверить: тесты 2.5 проходят

- [ ] 4.3 Написать тесты формы: ошибки у полей, срок в годах, пересчёт при изменении, устаревший результат; реализовать форму; проверить: тесты проходят
