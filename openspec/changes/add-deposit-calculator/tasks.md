# Задачи

План рассчитан на разработку по принципу «тесты до кода». Каждая группа — отдельная ветка и
отдельный запрос на слияние в `main`; внутри группы коммиты мелкие: сначала коммит с падающими
тестами, затем коммит с реализацией. Название каждого теста содержит название сценария
спецификации, чтобы покрытие можно было проверить по списку сценариев.

Порядок групп задаёт зависимости: 1 → 2 → 3 → (4, 5) → 6 → 7.

- [x] 1.2 Сверить через context7 (при его отсутствии — по официальной документации) актуальные версии и интерфейсы Vue, Vite, Vitest, Vue Test Utils, decimal.js, Chart.js, vue-chartjs, Playwright, axe; записать версии в `package.json` точными значениями; проверить: установленные версии совпадают с записанными, в отчёте указан источник сверки
- [x] 1.3 Добавить проверку имён классов по БЭМ (линтер стилей или собственный тест по шаблону `блок__элемент--модификатор`), подобрав инструмент по документации; проверить: на заведомо неверном имени класса проверка падает, на верном проходит
- [x] 1.4 Написать `CLAUDE.md`: стек, команды, структура папок, правила (деньги только через `decimal.js`; тесты до кода; БЭМ; токены вместо значений; текст интерфейса на русском; процесс OpenSpec; сообщения коммитов на русском); проверить: каждая команда из файла выполняется как написано
